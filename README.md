# Python Basic

Домашние задания курса Python Basic. Каждое задание лежит в отдельной папке.

## Требования

- Python 3.10+
- `basics` — только стандартная библиотека, зависимости не нужны.
- `pizza` — зависимости из `pizza/requirements.txt`.

## Запуск

```bash
python basics/task_1.py
```

Остальные задачи запускаются так же: `basics/task_2.py` … `basics/task_5.py`.

## Проверка стиля

```bash
pip install flake8
flake8 .
```
