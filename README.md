# Python Basic – практика по классам

Программа извлекает ключевые слова из текста по весам TF-IDF. В файле `classes/hw_classes_base.py` реализованы `CountVectorizer`, `BinaryVectorizer`, `TfidfVectorizer` и `KeywordExtractor`.

## Требования

Python 3.10 или новее. Устанавливать дополнительные зависимости для запуска не нужно.

## Запуск

Из корня репозитория выполни:

```bash
python classes/hw_classes_base.py
```

Демо показывает расчёт TF-IDF, работу с учётом регистра, повторное обучение и выбор ключевых слов для новых текстов.
